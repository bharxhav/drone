# Natural-language and AIP capabilities

- Method: `POST`
- Endpoint: `/eddie/api/natural-language-converter/aip-enabled`
- Observed response: `200 OK`

```json
{}
```

Returns whether AIP is enabled for Pipeline Builder, the enabled/disabled natural-language features, and available language-model RIDs. Observed enabled features included copilot, suggestions, proposal descriptions, search, explain, regex, and generation.
